# 광고 리포트 봇

박연수 브랜드(금별맥주 등)의 Meta + TikTok 광고 캠페인 성과를 주 2회 자동으로 가져와
[docs/index.html](docs/index.html)로 갱신하고 GitHub Pages에 올리는 무인 파이프라인.

```
목/월 09:00 KST -> Meta + TikTok API 인사이트 pull -> CPV 효율 계산 -> docs/index.html 생성 -> GitHub Pages 배포
```

사람이 대화창을 열어서 "갱신해줘"라고 말할 필요 없이, GitHub Actions가 대신 돈다.

## 왜 이렇게 만들었나

- 캠페인마다 광고금액, 타겟 설정이 매번 달라서, 절대 조회수가 아니라
  **조회 1회당 비용(CPV)** 으로 비교해야 어떤 조합이 효율적이었는지 보인다.
- CPV 하위 1/3은 초록, 상위 1/3은 빨강으로 표에도 막대그래프에도 동일하게 표시한다
  (숫자만으로도 판단 가능하도록 텍스트 배지 형태, 색만으로 정보 전달하지 않음).
- **조회수 = 영상 재생수**(Meta, TikTok 둘 다 `video_play_actions`), 그 옆에 **트루플레이**
  (Meta `actions.video_view` 3초 조회, TikTok `video_watched_6s` 6초 조회)를 따로 보여준다.
  조회당 비용은 재생수 기준. 예전엔 3초/6초 값을 메인 조회수로 써서 월 합계가 실제보다
  훨씬 작게 나왔다(2026년 9월: 15.9만 -> 실제 재생 117만).
- 데이터는 **광고그룹 x 일자** 단위(`DAILY`)로 받는다. 월 합계는 일자 기준으로 더하므로
  8/31~9/6처럼 월을 걸친 캠페인은 8월분/9월분이 실제 집행일대로 나뉜다.
- 메타, 틱톡은 항상 같은 날 시작하므로 **시작일이 두 플랫폼을 묶는 조인 키**다.
  같은 날 시작한 세팅들을 한 "캠페인"으로 묶어 표 한 줄로 보여준다.
- 효율 색상: 캠페인(기간) 전체 이력 중 조회당 비용 하위 1/3 초록, 상위 1/3 빨강.
  세팅 카드는 같은 플랫폼 안에서만 비교한다(틱톡이 구조적으로 싸서 섞으면 의미 없음).

## 화면 구조

1. **월 선택** (기본 = 최신 월, "전체 기간"도 있음)
2. **KPI 타일** - 선택한 달의 광고비, 조회수, 트루플레이, 조회당 비용, 트루플레이율,
   집행 캠페인 수. 모두 Meta/TikTok 분리 표시
3. **이 달 집행 캠페인** - 그 달에 돈이 쓰인 캠페인 목록. 행을 누르면 세팅 카드
   (예산, 목표, 입찰, 연령, 지면, 지표, 한줄 총평)가 펼쳐짐. 월 걸침 배지 표시
4. **월별 추이** - 모든 달의 합계와 그 달 캠페인 이름. 행을 누르면 그 달로 이동
5. **캠페인별 조회당 비용 막대그래프**
6. **다음 세팅 가이드** - 목표(optimization_goal)별 조회당 비용 비교로 추천 목표·예산 자동 작성
## 로컬에서 돌려보기

```bash
pip install -r requirements.txt
python src/report.py
```

`.env`에 아래 값을 넣어두면 로컬에서도 동일하게 동작한다
(GitHub Actions에서는 같은 이름의 저장소 시크릿을 읽는다):

```
META_ACCESS_TOKEN=...
META_AD_ACCOUNT_ID=act_...
TIKTOK_ACCESS_TOKEN=...
TIKTOK_ADVERTISER_ID=...
```

TikTok 변수가 없으면 `build_tiktok()`이 빈 배열을 반환하고 Meta 데이터만으로
리포트가 생성된다 (한쪽 토큰이 만료돼도 전체가 죽지 않음).

## 남은 일

- 자연조회수(광고 아닌 순수 도달)는 API로 못 가져와서 계속 수동 입력 필요 -
  당장은 이 리포트에서 빠져 있음
- Meta 토큰은 System User 장기 토큰이라 자동 만료가 없지만, TikTok 액세스 토큰은
  주기적 재인증이 필요할 수 있음 - 리포트가 갑자기 TikTok 쪽만 비면 토큰 재발급부터
  의심할 것
- GitHub 기본 cron이 며칠씩 안 도는 사례가 morningpick에서 있었다 -
  이 리포지토리도 그러면 `workflow_dispatch`를 외부 크론(cron-job.org 등)으로
  두드리는 방식으로 바꾼다
